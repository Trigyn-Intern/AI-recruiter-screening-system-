# Migration Analysis

## Goal
Plan safe changes to APIs, persisted vector-store data, prompts, dependencies, and UI contracts.

## Required checks
- Identify affected consumers and stored-data versions.
- Preserve backwards compatibility where possible.
- Provide a migration and rollback path.
- Validate data before and after migration.
- Add tests for both old and new formats.

## Output
Include scope, compatibility risk, migration steps, rollback steps, validation plan,
and release notes.
