# Performance Analysis

## Goal
Find repository-wide performance bottlenecks.

## Inspect
- Model startup and embedding-generation latency.
- FAISS indexing and search performance.
- API request latency, concurrency, and memory use.
- Large PDF/DOCX parsing behavior.
- Frontend bundle size and Lighthouse metrics.
- Repeated network calls, expensive renders, and missing caching.

## Output
Include baseline metric, bottleneck, likely cause, impact, recommendation,
measurement method, and expected improvement.
