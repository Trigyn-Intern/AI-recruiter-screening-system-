# Duplicate Code Analysis

## Goal
Detect repeated logic that creates inconsistent behavior or unnecessary maintenance.

## Inspect
- Validation logic across frontend, Express, and FastAPI.
- Prompt construction and LLM response parsing.
- Authentication and authorization checks.
- Error formatting and API client code.
- Test setup and fixtures.

## Output
Show duplicated locations, why consolidation is safe or unsafe, the proposed owner
module, migration steps, and regression tests required.
