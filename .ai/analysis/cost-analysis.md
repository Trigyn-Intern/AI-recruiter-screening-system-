# Cost Analysis

## Goal
Estimate and control infrastructure and AI-provider cost.

## Inspect
- Hosted LLM token usage and request volume.
- Local Ollama compute and hardware cost.
- Embedding generation and storage growth.
- CI minutes, artifact storage, and dependency scanning cost.
- Cost of retries, failures, and unnecessary model calls.

## Output
Report current estimate, driver, budget threshold, optimization, and monitoring metric.
Never include API keys, invoice data, or sensitive account information.
