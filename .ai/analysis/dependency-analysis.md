# Dependency Analysis

## Goal
Review Python and Node dependencies for security, health, and unnecessary usage.

## Inspect
- Known vulnerabilities and unsupported versions.
- Duplicate packages serving the same purpose.
- Unused packages.
- License compatibility.
- Packages that process candidate data or make network calls.
- Version pinning and reproducible installs.

## Output
Report package, installed version, latest safe version, risk, evidence,
upgrade impact, and recommended action.
