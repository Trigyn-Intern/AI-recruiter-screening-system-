# Memory Management

## Purpose
Store durable engineering knowledge without retaining sensitive data.

## Allowed memory
Approved patterns, lessons learned, architecture decisions, anonymized issue summaries,
and reusable checklists.

## Prohibited memory
Resumes, candidate PII, secrets, access tokens, raw production logs, and private prompts
containing sensitive data.

## Rule
Keep knowledge concise, dated, reviewable, and traceable to source evidence.
