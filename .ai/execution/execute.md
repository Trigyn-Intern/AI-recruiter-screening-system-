# Execute Engine

## Purpose
Run the complete SDLC lifecycle from a single command.

## Responsibilities
- Accept a natural language task.
- Select the correct workflow.
- Load project configuration.
- Load required skills and knowledge.
- Build the execution prompt.
- Invoke the configured AI engine.
- Trigger reviews and report generation.
- Return a complete execution summary.

## Output
- Workflow used
- Skills executed
- Files modified
- Tests generated
- Reports created
- Risks identified
