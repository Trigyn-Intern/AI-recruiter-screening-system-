# Task Classifier

## Purpose
Determine the type of user request.

## Supported Tasks
- Feature Development
- Bug Fix
- Hotfix
- Refactoring
- Documentation
- Testing
- Security Review
- Code Review
- Performance Optimization
- Dependency Upgrade

## Rules
- Choose the closest matching task.
- If confidence is below 80%, ask for clarification.
- Output task type and confidence.
